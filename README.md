# 🌴 Mangaba Trip - Hack.IA++ 2025

> **Trilha:** CustomerTech AI  
> **Tecnologia:** Mangaba.AI Framework + Python + Streamlit

## 💡 O Problema
Turistas perdem horas planejando viagens e, muitas vezes, acabam em destinos que não combinam com seu perfil. A informação é descentralizada e impessoal.

## 🚀 A Solução
O **Mangaba Trip** é uma plataforma de hiper-personalização turística. Utilizamos o framework **Mangaba.AI** para criar um sistema híbrido que une:
1.  **Filtragem Colaborativa:** Analisa perfis similares (ex: "Quem gostou de Aracaju também amou Xingó").
2.  **Agentes Generativos:** O Agente Mangaba cria roteiros persuasivos e explica *por que* aquele destino é ideal para você.

## 🛠️ Tecnologias Utilizadas
* **Mangaba.AI (v2.0):** Orquestração de agentes e geração de texto persuasivo.
* **Python/Streamlit:** Interface web responsiva e motor de recomendação.
* **Scikit-Learn:** Algoritmo de similaridade de cosseno para match de usuários.

## 📊 Validação (Estação 1)
Entrevistamos 10 turistas na Orla de Atalaia:
* **80%** disseram que "perdem tempo demais pesquisando".
* **60%** já se arrependeram de ir a um lugar por indicação genérica da internet.
* Validamos que a "Curadoria Inteligente" é uma dor real.
